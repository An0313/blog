### 页面高度小于100vh

无需处理

### 页面高度大于等于100vh

```javascript
// input onFocus 事件中
setTimeout(() => {
  // 1、  element.scrollIntoView();
  // 2、  Element.scrollIntoViewIfNeeded()
  // 3、  window.scrollTo(0, document.body.scrollHeight)
}, 300)
```

以上方法需要配合css，保证页面不小于100vh

```css
.page {
    min-height: 100vh;
}
```
