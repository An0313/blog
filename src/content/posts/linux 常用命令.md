### 删除命令
```
  # 常规删除a.txt文件
  rm a.txt
  
  # 强行删除file.log文件
   rm -f file.log
   
  # 删除dirname目录下的所有东西
  rm -R dir dirname
  
  # 删除以 -f 开头的文件
  touch ./-f
  
  # 删除文件夹
  rm -rf 文件夹
```
